

<h3 id="r5Efx"><font style="background-color:#F8F8F8;">3.2 静态方法</font></h3>
+ <font style="background-color:#F8F8F8;">在开发时，如果需要在</font>**<font style="background-color:#F8F8F8;">类</font>**<font style="background-color:#F8F8F8;">中封装一个方法，这个方法：</font>
    - 既 **不需要** 访问 **实例属性** 或者调用 **实例方法**
    - 也 **不需要** 访问 **类属性** 或者调用 **类方法**
+ <font style="background-color:#F8F8F8;">这个时候，可以把这个方法封装成一个 </font>**<font style="background-color:#F8F8F8;">静态方法</font>**

****

<h2 id="toc_4">`__new__` 方法</h2>
+ <font style="background-color:#F8F8F8;">使用 </font>**<font style="background-color:#F8F8F8;">类名()</font>**<font style="background-color:#F8F8F8;"> 创建对象时，</font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 的解释器 </font>**<font style="background-color:#F8F8F8;">首先</font>**<font style="background-color:#F8F8F8;"> 会 调用 </font>`<font style="background-color:#F8F8F8;">__new__</font>`<font style="background-color:#F8F8F8;"> 方法为对象 </font>**<font style="background-color:#F8F8F8;">分配空间</font>**
+ `<font style="background-color:#F8F8F8;">__new__</font>`<font style="background-color:#F8F8F8;">是一个 由</font>`<font style="background-color:#F8F8F8;">object</font>`<font style="background-color:#F8F8F8;">基类提供的</font>**<font style="background-color:#F8F8F8;">内置的静态方法</font>**<font style="background-color:#F8F8F8;">，主要作用有两个：</font>
    - 1) 在内存中为对象 **分配空间**
    - 2) **返回** 对象的引用
+ `<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 的解释器获得对象的 </font>**<font style="background-color:#F8F8F8;">引用</font>**<font style="background-color:#F8F8F8;"> 后，将引用作为 </font>**<font style="background-color:#F8F8F8;">第一个参数</font>**<font style="background-color:#F8F8F8;">，传递给 </font>`<font style="background-color:#F8F8F8;">__init__</font>`<font style="background-color:#F8F8F8;"> 方法</font>

> <font style="background-color:#F8F8F8;">重写 </font>`<font style="background-color:#F8F8F8;">__new__</font>`<font style="background-color:#F8F8F8;"> 方法 的代码非常固定！</font>
>

+ <font style="background-color:#F8F8F8;">重写 </font>`<font style="background-color:#F8F8F8;">__new__</font>`<font style="background-color:#F8F8F8;"> 方法 </font>**<font style="background-color:#F8F8F8;">一定要</font>**<font style="background-color:#F8F8F8;"> </font>`<font style="background-color:#F8F8F8;">return super().__new__(cls)</font>`
+ <font style="background-color:#F8F8F8;">否则 Python 的解释器 </font>**<font style="background-color:#F8F8F8;">得不到</font>**<font style="background-color:#F8F8F8;"> 分配了空间的 </font>**<font style="background-color:#F8F8F8;">对象引用</font>**<font style="background-color:#F8F8F8;">，</font>**<font style="background-color:#F8F8F8;">就不会调用对象的初始化方法</font>**
+ <font style="background-color:#F8F8F8;">注意：</font>`<font style="background-color:#F8F8F8;">__new__</font>`<font style="background-color:#F8F8F8;"> 是一个静态方法，在调用时需要 </font>**<font style="background-color:#F8F8F8;">主动传递</font>**<font style="background-color:#F8F8F8;"> </font>`<font style="background-color:#F8F8F8;">cls</font>`<font style="background-color:#F8F8F8;"> 参数</font>
