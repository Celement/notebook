<h3 id="toc_7"><font style="background-color:#F8F8F8;">1.1 操作文件的套路</font></h3>
<font style="background-color:#F8F8F8;">在 </font>**<font style="background-color:#F8F8F8;">计算机</font>**<font style="background-color:#F8F8F8;"> 中要操作文件的套路非常固定，一共包含</font>**<font style="background-color:#F8F8F8;">三个步骤</font>**<font style="background-color:#F8F8F8;">：</font>

1. <font style="background-color:#F8F8F8;">打开文件</font>
2. <font style="background-color:#F8F8F8;">读、写文件</font>
    - **读** 将文件内容读入内存
    - **写** 将内存内容写入文件
3. <font style="background-color:#F8F8F8;">关闭文件</font>

<h3 id="toc_8"><font style="background-color:#F8F8F8;">1.2 操作文件的函数/方法</font></h3>
+ <font style="background-color:#F8F8F8;">在 </font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 中要操作文件需要记住 1 个函数和 3 个方法</font>

| 序号 | 函数/方法 | 说明 |
| :--- | :--- | :--- |
| 01 | open | 打开文件，并且返回文件操作对象 |
| 02 | read | 将文件内容读取到内存 |
| 03 | write | 将指定内容写入文件 |
| 04 | close | 关闭文件 |


+ `<font style="background-color:#F8F8F8;">open</font>`<font style="background-color:#F8F8F8;"> 函数负责打开文件，并且返回文件对象</font>
+ `<font style="background-color:#F8F8F8;">read</font>`<font style="background-color:#F8F8F8;">/</font>`<font style="background-color:#F8F8F8;">write</font>`<font style="background-color:#F8F8F8;">/</font>`<font style="background-color:#F8F8F8;">close</font>`<font style="background-color:#F8F8F8;"> 三个方法都需要通过 </font>**<font style="background-color:#F8F8F8;">文件对象</font>**<font style="background-color:#F8F8F8;"> 来调用</font>

<h3 id="toc_9"><font style="background-color:#F8F8F8;">1.3 read 方法 —— 读取文件</font></h3>
+ `<font style="background-color:#F8F8F8;">open</font>`<font style="background-color:#F8F8F8;">函数的第一个参数是要打开的文件名（文件名区分大小写）</font>
    - 如果文件 **存在**，返回 **文件操作对象**
    - 如果文件 **不存在**，会 **抛出异常**
+ `<font style="background-color:#F8F8F8;">read</font>`<font style="background-color:#F8F8F8;"> 方法可以一次性 </font>**<font style="background-color:#F8F8F8;">读入</font>**<font style="background-color:#F8F8F8;"> 并 </font>**<font style="background-color:#F8F8F8;">返回</font>**<font style="background-color:#F8F8F8;"> 文件的 </font>**<font style="background-color:#F8F8F8;">所有内容</font>**
+ `<font style="background-color:#F8F8F8;">close</font>`<font style="background-color:#F8F8F8;">方法负责</font>**<font style="background-color:#F8F8F8;">关闭文件</font>**
    - 如果 **忘记关闭文件**，**会造成系统资源消耗，而且会影响到后续对文件的访问**
+ **<font style="background-color:#F8F8F8;">注意</font>**<font style="background-color:#F8F8F8;">：</font>`<font style="background-color:#F8F8F8;">read</font>`<font style="background-color:#F8F8F8;"> 方法执行后，会把 </font>**<font style="background-color:#F8F8F8;">文件指针</font>**<font style="background-color:#F8F8F8;"> 移动到 </font>**<font style="background-color:#F8F8F8;">文件的末尾</font>**

```plain
# 1. 打开 - 文件名需要注意大小写
file = open("README")
# 2. 读取
text = file.read()
print(text)
# 3. 关闭
file.close()
```

**<font style="background-color:#F8F8F8;">提示</font>**

+ <font style="background-color:#F8F8F8;">在开发中，通常会先编写 </font>**<font style="background-color:#F8F8F8;">打开</font>**<font style="background-color:#F8F8F8;"> 和 </font>**<font style="background-color:#F8F8F8;">关闭</font>**<font style="background-color:#F8F8F8;"> 的代码，再编写中间针对文件的 </font>**<font style="background-color:#F8F8F8;">读/写</font>**<font style="background-color:#F8F8F8;"> 操作！</font>

<h4 id="toc_10"><font style="background-color:#F8F8F8;">文件指针（知道）</font></h4>
+ **<font style="background-color:#F8F8F8;">文件指针</font>**<font style="background-color:#F8F8F8;"> 标记 </font>**<font style="background-color:#F8F8F8;">从哪个位置开始读取数据</font>**
+ **<font style="background-color:#F8F8F8;">第一次打开</font>**<font style="background-color:#F8F8F8;"> 文件时，通常 </font>**<font style="background-color:#F8F8F8;">文件指针会指向文件的开始位置</font>**
+ <font style="background-color:#F8F8F8;">当执行了</font>`<font style="background-color:#F8F8F8;">read</font>`<font style="background-color:#F8F8F8;">方法后，</font>**<font style="background-color:#F8F8F8;">文件指针</font>**<font style="background-color:#F8F8F8;">会移动到</font>**<font style="background-color:#F8F8F8;">读取内容的末尾</font>**
    - 默认情况下会移动到 **文件末尾**

**<font style="background-color:#F8F8F8;">思考</font>**

+ <font style="background-color:#F8F8F8;">如果执行了一次 </font>`<font style="background-color:#F8F8F8;">read</font>`<font style="background-color:#F8F8F8;"> 方法，读取了所有内容，那么再次调用 </font>`<font style="background-color:#F8F8F8;">read</font>`<font style="background-color:#F8F8F8;"> 方法，还能够获得到内容吗？</font>

**<font style="background-color:#F8F8F8;">答案</font>**

+ <font style="background-color:#F8F8F8;">不能</font>
+ <font style="background-color:#F8F8F8;">第一次读取之后，文件指针移动到了文件末尾，再次调用不会读取到任何的内容</font>

<h3 id="toc_11"><font style="background-color:#F8F8F8;">1.4 打开文件的方式</font></h3>
+ `<font style="background-color:#F8F8F8;">open</font>`<font style="background-color:#F8F8F8;"> 函数默认以 </font>**<font style="background-color:#F8F8F8;">只读方式</font>**<font style="background-color:#F8F8F8;"> 打开文件，并且返回文件对象</font>

<font style="background-color:#F8F8F8;">语法如下：</font>

```plain
f = open("文件名", "访问方式")
```

| 访问方式 | 说明 |
| :---: | :--- |
| r | 以**只读**方式打开文件。文件的指针将会放在文件的开头，这是**默认模式**。如果文件不存在，抛出异常 |
| w | 以**只写**方式打开文件。如果文件存在会被覆盖。如果文件不存在，创建新文件 |
| a | 以**追加**方式打开文件。如果该文件已存在，文件指针将会放在文件的结尾。如果文件不存在，创建新文件进行写入 |
| r+ | 以**读写**方式打开文件。文件的指针将会放在文件的开头。如果文件不存在，抛出异常 |
| w+ | 以**读写**方式打开文件。如果文件存在会被覆盖。如果文件不存在，创建新文件 |
| a+ | 以**读写**方式打开文件。如果该文件已存在，文件指针将会放在文件的结尾。如果文件不存在，创建新文件进行写入 |


**<font style="background-color:#F8F8F8;">提示</font>**

+ <font style="background-color:#F8F8F8;">频繁的移动文件指针，</font>**<font style="background-color:#F8F8F8;">会影响文件的读写效率</font>**<font style="background-color:#F8F8F8;">，开发中更多的时候会以 </font>**<font style="background-color:#F8F8F8;">只读</font>**<font style="background-color:#F8F8F8;">、</font>**<font style="background-color:#F8F8F8;">只写</font>**<font style="background-color:#F8F8F8;"> 的方式来操作文件</font>

**<font style="background-color:#F8F8F8;">写入文件示例</font>**

```plain
# 打开文件
f = open("README", "w")
f.write("hello python！\n")
f.write("今天天气真好")
# 关闭文件
f.close()
```

<h3 id="toc_12"><font style="background-color:#F8F8F8;">1.5 按行读取文件内容</font></h3>
+ `<font style="background-color:#F8F8F8;">read</font>`<font style="background-color:#F8F8F8;"> 方法默认会把文件的 </font>**<font style="background-color:#F8F8F8;">所有内容</font>**<font style="background-color:#F8F8F8;"> </font>**<font style="background-color:#F8F8F8;">一次性读取到内存</font>**
+ <font style="background-color:#F8F8F8;">如果文件太大，对内存的占用会非常严重</font>

<h4 id="toc_13">`<font style="background-color:#F8F8F8;">readline</font>`<font style="background-color:#F8F8F8;"> 方法</font></h4>
+ `<font style="background-color:#F8F8F8;">readline</font>`<font style="background-color:#F8F8F8;"> 方法可以一次读取一行内容</font>
+ <font style="background-color:#F8F8F8;">方法执行后，会把 </font>**<font style="background-color:#F8F8F8;">文件指针</font>**<font style="background-color:#F8F8F8;"> 移动到下一行，准备再次读取</font>

**<font style="background-color:#F8F8F8;">读取大文件的正确姿势</font>**

```plain
# 打开文件
file = open("README")
while True:
    # 读取一行内容
    text = file.readline()
    # 判断是否读到内容
    if not text:
        break
    # 每读取一行的末尾已经有了一个 `\n`
    print(text, end="")
# 关闭文件
file.close()
```



<h4 id="toc_15"><font style="background-color:#F8F8F8;">小文件复制</font></h4>
+ <font style="background-color:#F8F8F8;">打开一个已有文件，读取完整内容，并写入到另外一个文件</font>

```plain
# 1. 打开文件
file_read = open("README")
file_write = open("README[复件]", "w")
# 2. 读取并写入文件
text = file_read.read()
file_write.write(text)
# 3. 关闭文件
file_read.close()
file_write.close()
```

<h4 id="toc_16"><font style="background-color:#F8F8F8;">大文件复制</font></h4>
+ <font style="background-color:#F8F8F8;">打开一个已有文件，逐行读取内容，并顺序写入到另外一个文件</font>

```plain
# 1. 打开文件
file_read = open("README")
file_write = open("README[复件]", "w")
# 2. 读取并写入文件
while True:
    # 每次读取一行
    text = file_read.readline()
    # 判断是否读取到内容
    if not text:
        break
    file_write.write(text)
# 3. 关闭文件
file_read.close()
file_write.close()
```

<h2 id="toc_17">03. 文件/目录的常用管理操作</h2>
+ <font style="background-color:#F8F8F8;">在</font>**<font style="background-color:#F8F8F8;">终端</font>**<font style="background-color:#F8F8F8;">/</font>**<font style="background-color:#F8F8F8;">文件浏览器</font>**<font style="background-color:#F8F8F8;">、 中可以执行常规的</font>**<font style="background-color:#F8F8F8;">文件</font>**<font style="background-color:#F8F8F8;">/</font>**<font style="background-color:#F8F8F8;">目录</font>**<font style="background-color:#F8F8F8;">管理操作，例如：</font>
    - 创建、重命名、删除、改变路径、查看目录内容、……
+ <font style="background-color:#F8F8F8;">在 </font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 中，如果希望通过程序实现上述功能，需要导入 </font>`<font style="background-color:#F8F8F8;">os</font>`<font style="background-color:#F8F8F8;"> 模块</font>

| :--- | :--- | :--- | :--- |
| 01 | rename | 重命名文件 | `os.rename(源文件名, 目标文件名)` |
| 02 | remove | 删除文件 | `os.remove(文件名)` |


<h3 id="toc_19"><font style="background-color:#F8F8F8;">目录操作</font></h3>

> <font style="background-color:#F8F8F8;">提示：文件或者目录操作都支持 </font>**<font style="background-color:#F8F8F8;">相对路径</font>**<font style="background-color:#F8F8F8;"> 和 </font>**<font style="background-color:#F8F8F8;">绝对路径</font>**
>
