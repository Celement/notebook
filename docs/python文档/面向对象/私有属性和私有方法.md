<h2 id="toc_1">01. 应用场景及定义方式</h2>
**<font style="background-color:#F8F8F8;">应用场景</font>**

+ <font style="background-color:#F8F8F8;">在实际开发中，</font>**<font style="background-color:#F8F8F8;">对象</font>**<font style="background-color:#F8F8F8;"> 的 </font>**<font style="background-color:#F8F8F8;">某些属性或方法</font>**<font style="background-color:#F8F8F8;"> 可能只希望 </font>**<font style="background-color:#F8F8F8;">在对象的内部被使用</font>**<font style="background-color:#F8F8F8;">，而 </font>**<font style="background-color:#F8F8F8;">不希望在外部被访问到</font>**
+ **<font style="background-color:#F8F8F8;">私有属性</font>**<font style="background-color:#F8F8F8;"> 就是 </font>**<font style="background-color:#F8F8F8;">对象</font>**<font style="background-color:#F8F8F8;"> 不希望公开的 </font>**<font style="background-color:#F8F8F8;">属性</font>**
+ **<font style="background-color:#F8F8F8;">私有方法</font>**<font style="background-color:#F8F8F8;"> 就是 </font>**<font style="background-color:#F8F8F8;">对象</font>**<font style="background-color:#F8F8F8;"> 不希望公开的 </font>**<font style="background-color:#F8F8F8;">方法</font>**

**<font style="background-color:#F8F8F8;">定义方式</font>**

+ <font style="background-color:#F8F8F8;">在 </font>**<font style="background-color:#F8F8F8;">定义属性或方法时</font>**<font style="background-color:#F8F8F8;">，在 </font>**<font style="background-color:#F8F8F8;">属性名或者方法名前</font>**<font style="background-color:#F8F8F8;"> 增加 </font>**<font style="background-color:#F8F8F8;">两个下划线</font>**<font style="background-color:#F8F8F8;">，定义的就是 </font>**<font style="background-color:#F8F8F8;">私有</font>**<font style="background-color:#F8F8F8;"> 属性或方法￼</font>

```plain
class Women:
    def __init__(self, name):
        self.name = name
        # 不要问女生的年龄
        self.__age = 18
    def __secret(self):
        print("我的年龄是 %d" % self.__age)
xiaofang = Women("小芳")
# 私有属性，外部不能直接访问
# print(xiaofang.__age)
# 私有方法，外部不能直接调用
# xiaofang.__secret()
```

<h2 id="toc_2">02. 伪私有属性和私有方法（科普）</h2>
> <font style="background-color:#F8F8F8;">提示：在日常开发中，</font>**<font style="background-color:#F8F8F8;">不要使用这种方式</font>**<font style="background-color:#F8F8F8;">，</font>**<font style="background-color:#F8F8F8;">访问对象的 私有属性 或 私有方法</font>**
>

`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 中，并没有 </font>**<font style="background-color:#F8F8F8;">真正意义</font>**<font style="background-color:#F8F8F8;"> 的 </font>**<font style="background-color:#F8F8F8;">私有</font>**

+ <font style="background-color:#F8F8F8;">在给 </font>**<font style="background-color:#F8F8F8;">属性</font>**<font style="background-color:#F8F8F8;">、</font>**<font style="background-color:#F8F8F8;">方法</font>**<font style="background-color:#F8F8F8;"> 命名时，实际是对 </font>**<font style="background-color:#F8F8F8;">名称</font>**<font style="background-color:#F8F8F8;"> 做了一些特殊处理，使得外界无法访问到</font>
+ **<font style="background-color:#F8F8F8;">处理方式</font>**<font style="background-color:#F8F8F8;">：在 </font>**<font style="background-color:#F8F8F8;">名称</font>**<font style="background-color:#F8F8F8;"> 前面加上 </font>`<font style="background-color:#F8F8F8;">_类名</font>`<font style="background-color:#F8F8F8;"> => </font>`<font style="background-color:#F8F8F8;">_类名__名称</font>`

```plain
# 私有属性，外部不能直接访问到
print(xiaofang._Women__age)
# 私有方法，外部不能直接调用
xiaofang._Women__secret()
```
