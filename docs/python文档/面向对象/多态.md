<h2 id="toc_1">目标</h2>
+ <font style="background-color:#F8F8F8;">多态</font>

**<font style="background-color:#F8F8F8;">面向对象三大特性</font>**

1. **<font style="background-color:#F8F8F8;">封装</font>**<font style="background-color:#F8F8F8;">根据</font>**<font style="background-color:#F8F8F8;">职责</font>**<font style="background-color:#F8F8F8;">将</font>**<font style="background-color:#F8F8F8;">属性</font>**<font style="background-color:#F8F8F8;">和</font>**<font style="background-color:#F8F8F8;">方法</font>****<font style="background-color:#F8F8F8;">封装</font>**<font style="background-color:#F8F8F8;">到一个抽象的</font>**<font style="background-color:#F8F8F8;">类</font>**<font style="background-color:#F8F8F8;">中</font>
    - 定义类的准则
2. **<font style="background-color:#F8F8F8;">继承</font>****<font style="background-color:#F8F8F8;">实现代码的重用</font>**<font style="background-color:#F8F8F8;">，相同的代码不需要重复的编写</font>
    - 设计类的技巧
    - 子类针对自己特有的需求，编写特定的代码
3. **<font style="background-color:#F8F8F8;">多态,对于同一个方法调用的对象不同,或者传入的对象的不同产生不同的结果</font>**
    - **多态** 可以 **增加代码的灵活度**
    - 以 **继承** 和 **重写父类方法** 为前提
    - 是调用方法的技巧，**不会影响到类的内部设计**
