<h2 id="toc_2">01. `dir` 内置函数（知道）</h2>
+ <font style="background-color:#F8F8F8;">在 </font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 中 </font>**<font style="background-color:#F8F8F8;">对象几乎是无所不在的</font>**<font style="background-color:#F8F8F8;">，我们之前学习的 </font>**<font style="background-color:#F8F8F8;">变量</font>**<font style="background-color:#F8F8F8;">、</font>**<font style="background-color:#F8F8F8;">数据</font>**<font style="background-color:#F8F8F8;">、</font>**<font style="background-color:#F8F8F8;">函数</font>**<font style="background-color:#F8F8F8;"> 都是对象</font>

<font style="background-color:#F8F8F8;">在 </font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 中可以使用以下两个方法验证：</font>

1. <font style="background-color:#F8F8F8;">在 </font>**<font style="background-color:#F8F8F8;">标识符</font>**<font style="background-color:#F8F8F8;"> / </font>**<font style="background-color:#F8F8F8;">数据</font>**<font style="background-color:#F8F8F8;"> 后输入一个 </font>`<font style="background-color:#F8F8F8;">.</font>`<font style="background-color:#F8F8F8;">，然后按下 </font>`<font style="background-color:#F8F8F8;">TAB</font>`<font style="background-color:#F8F8F8;"> 键，</font>`<font style="background-color:#F8F8F8;">iPython</font>`<font style="background-color:#F8F8F8;"> 会提示该对象能够调用的 </font>**<font style="background-color:#F8F8F8;">方法列表</font>**
2. <font style="background-color:#F8F8F8;">使用内置函数 </font>`<font style="background-color:#F8F8F8;">dir</font>`<font style="background-color:#F8F8F8;"> 传入 </font>**<font style="background-color:#F8F8F8;">标识符</font>**<font style="background-color:#F8F8F8;"> / </font>**<font style="background-color:#F8F8F8;">数据</font>**<font style="background-color:#F8F8F8;">，可以查看对象内的 </font>**<font style="background-color:#F8F8F8;">所有属性及方法</font>**

**<font style="background-color:#F8F8F8;">提示</font>**<font style="background-color:#F8F8F8;"> </font>`<font style="background-color:#F8F8F8;">__方法名__</font>`<font style="background-color:#F8F8F8;"> 格式的方法是 </font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 提供的 </font>**<font style="background-color:#F8F8F8;">内置方法 / 属性</font>**<font style="background-color:#F8F8F8;">，稍后会给大家介绍一些常用的 内置方法 / 属性</font>

| 序号 | 方法名 | 类型 | 作用 |
| :---: | :---: | :---: | :--- |
| 01 | `__new__` | 方法 | **创建对象**时，会被 **自动** 调用 |
| 02 | `__init__` | 方法 | **对象被初始化**时，会被 **自动** 调用 |
| 03 | `__del__` | 方法 | **对象被从内存中销毁**前，会被 **自动** 调用 |
| 04 | `__str__` | 方法 | 返回**对象的描述信息**，`print`<br/> 函数输出使用 |


**<font style="background-color:#F8F8F8;">提示</font>**<font style="background-color:#F8F8F8;"> 利用好 </font>`<font style="background-color:#F8F8F8;">dir()</font>`<font style="background-color:#F8F8F8;"> 函数，在学习时很多内容就不需要死记硬背了</font>

<h2 id="toc_3">02. 定义简单的类（只包含方法）</h2>
> **<font style="background-color:#F8F8F8;">面向对象</font>**<font style="background-color:#F8F8F8;"> 是 </font>**<font style="background-color:#F8F8F8;">更大</font>**<font style="background-color:#F8F8F8;"> 的 </font>**<font style="background-color:#F8F8F8;">封装</font>**<font style="background-color:#F8F8F8;">，在 </font>**<font style="background-color:#F8F8F8;">一个类中 封装 多个方法</font>**<font style="background-color:#F8F8F8;">，这样 </font>**<font style="background-color:#F8F8F8;">通过这个类创建出来的对象，就可以直接调用这些方法了</font>**<font style="background-color:#F8F8F8;">！</font>
>

<h3 id="toc_4"><font style="background-color:#F8F8F8;">2.1 定义只包含方法的类</font></h3>
+ <font style="background-color:#F8F8F8;">在 </font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 中要定义一个只包含方法的类，语法格式如下：</font>

```plain
class 类名:
    def 方法1(self, 参数列表):
        pass
    
    def 方法2(self, 参数列表):
        pass
```

+ **<font style="background-color:#F8F8F8;">方法</font>**<font style="background-color:#F8F8F8;"> 的定义格式和之前学习过的</font>**<font style="background-color:#F8F8F8;">函数</font>**<font style="background-color:#F8F8F8;"> 几乎一样</font>
+ <font style="background-color:#F8F8F8;">区别在于第一个参数必须是 </font>`<font style="background-color:#F8F8F8;">self</font>`<font style="background-color:#F8F8F8;">，大家暂时先记住，稍后介绍 </font>`<font style="background-color:#F8F8F8;">self</font>`

> <font style="background-color:#F8F8F8;">注意：</font>**<font style="background-color:#F8F8F8;">类名</font>**<font style="background-color:#F8F8F8;"> 的 命名规则 要符合 </font>**<font style="background-color:#F8F8F8;">大驼峰命名法</font>**
>

<h3 id="toc_5"><font style="background-color:#F8F8F8;">2.2 创建对象</font></h3>
+ <font style="background-color:#F8F8F8;">当一个类定义完成之后，要使用这个类来创建对象，语法格式如下：</font>

```plain
对象变量 = 类名()
```

<h3 id="toc_6"><font style="background-color:#F8F8F8;">2.3 第一个面向对象程序</font></h3>
**<font style="background-color:#F8F8F8;">需求</font>**

+ **<font style="background-color:#F8F8F8;">小猫</font>**<font style="background-color:#F8F8F8;"> 爱 </font>**<font style="background-color:#F8F8F8;">吃</font>**<font style="background-color:#F8F8F8;"> 鱼，</font>**<font style="background-color:#F8F8F8;">小猫</font>**<font style="background-color:#F8F8F8;"> 要 </font>**<font style="background-color:#F8F8F8;">喝</font>**<font style="background-color:#F8F8F8;"> 水</font>

**<font style="background-color:#F8F8F8;">分析</font>**

1. <font style="background-color:#F8F8F8;">定义一个猫类 </font>`<font style="background-color:#F8F8F8;">Cat</font>`
2. <font style="background-color:#F8F8F8;">定义两个方法 </font>`<font style="background-color:#F8F8F8;">eat</font>`<font style="background-color:#F8F8F8;"> 和 </font>`<font style="background-color:#F8F8F8;">drink</font>`
3. <font style="background-color:#F8F8F8;">按照需求 —— 不需要定义属性￼</font>

```plain
class Cat:
    """这是一个猫类"""
    def eat(self):
        print("小猫爱吃鱼")
    def drink(self):
        print("小猫在喝水")
tom = Cat()
tom.drink()
tom.eat()
```

<h4 id="toc_7"><font style="background-color:#F8F8F8;">引用概念的强调</font></h4>
> <font style="background-color:#F8F8F8;">在面向对象开发中，</font>**<font style="background-color:#F8F8F8;">引用</font>**<font style="background-color:#F8F8F8;">的概念是同样适用的！</font>
>

+ <font style="background-color:#F8F8F8;">在 </font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 中使用类 </font>**<font style="background-color:#F8F8F8;">创建对象之后</font>**<font style="background-color:#F8F8F8;">，</font>`<font style="background-color:#F8F8F8;">tom</font>`<font style="background-color:#F8F8F8;"> 变量中 仍然记录的是 </font>**<font style="background-color:#F8F8F8;">对象在内存中的地址</font>**
+ <font style="background-color:#F8F8F8;">也就是 </font>`<font style="background-color:#F8F8F8;">tom</font>`<font style="background-color:#F8F8F8;"> 变量 </font>**<font style="background-color:#F8F8F8;">引用</font>**<font style="background-color:#F8F8F8;"> 了 </font>**<font style="background-color:#F8F8F8;">新建的猫对象</font>**
+ <font style="background-color:#F8F8F8;">使用 </font>`<font style="background-color:#F8F8F8;">print</font>`<font style="background-color:#F8F8F8;"> 输出 </font>**<font style="background-color:#F8F8F8;">对象变量</font>**<font style="background-color:#F8F8F8;">，默认情况下，是能够输出这个变量 </font>**<font style="background-color:#F8F8F8;">引用的对象</font>**<font style="background-color:#F8F8F8;"> 是 </font>**<font style="background-color:#F8F8F8;">由哪一个类创建的对象</font>**<font style="background-color:#F8F8F8;">，以及 </font>**<font style="background-color:#F8F8F8;">在内存中的地址</font>**<font style="background-color:#F8F8F8;">（</font>**<font style="background-color:#F8F8F8;">十六进制表示</font>**<font style="background-color:#F8F8F8;">）</font>

> <font style="background-color:#F8F8F8;">提示：在计算机中，通常使用 </font>**<font style="background-color:#F8F8F8;">十六进制</font>**<font style="background-color:#F8F8F8;"> 表示 </font>**<font style="background-color:#F8F8F8;">内存地址</font>**
>
> + **<font style="background-color:#F8F8F8;">十进制</font>**<font style="background-color:#F8F8F8;"> 和 </font>**<font style="background-color:#F8F8F8;">十六进制</font>**<font style="background-color:#F8F8F8;"> 都是用来表达数字的，只是表示的方式不一样</font>
> + **<font style="background-color:#F8F8F8;">十进制</font>**<font style="background-color:#F8F8F8;"> 和 </font>**<font style="background-color:#F8F8F8;">十六进制</font>**<font style="background-color:#F8F8F8;"> 的数字之间可以来回转换</font>
>

+ `<font style="background-color:#F8F8F8;">%d</font>`<font style="background-color:#F8F8F8;"> 可以以 </font>**<font style="background-color:#F8F8F8;">10 进制</font>**<font style="background-color:#F8F8F8;"> 输出数字</font>

<h2 id="toc_9">03. 方法中的 `self` 参数</h2>
<h3 id="toc_10"><font style="background-color:#F8F8F8;">3.1 案例改造 —— 给对象增加属性</font></h3>
+ <font style="background-color:#F8F8F8;">在</font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;">中，要</font>**<font style="background-color:#F8F8F8;">给对象设置属性</font>**<font style="background-color:#F8F8F8;">，非常的容易，</font>**<font style="background-color:#F8F8F8;">但是不推荐使用</font>**
    - 因为：对象属性的封装应该封装在类的内部
+ <font style="background-color:#F8F8F8;">只需要在 </font>**<font style="background-color:#F8F8F8;">类的外部的代码</font>**<font style="background-color:#F8F8F8;"> 中直接通过 </font>`<font style="background-color:#F8F8F8;">.</font>`<font style="background-color:#F8F8F8;"> 设置一个属性即可</font>

> <font style="background-color:#F8F8F8;">注意：这种方式虽然简单，但是不推荐使用！</font>
>

```plain
tom.name = "Tom"
...
lazy_cat.name = "大懒猫"
```

<h3 id="toc_11"><font style="background-color:#F8F8F8;">3.2 使用 </font>`<font style="background-color:#F8F8F8;">self</font>`<font style="background-color:#F8F8F8;"> 在方法内部输出每一只猫的名字</font></h3>
> <font style="background-color:#F8F8F8;">由 </font>**<font style="background-color:#F8F8F8;">哪一个对象</font>**<font style="background-color:#F8F8F8;"> 调用的方法，方法内的 </font>`<font style="background-color:#F8F8F8;">self</font>`<font style="background-color:#F8F8F8;"> 就是 </font>**<font style="background-color:#F8F8F8;">哪一个对象的引用</font>**
>

+ <font style="background-color:#F8F8F8;">在类封装的方法内部，</font>`<font style="background-color:#F8F8F8;">self</font>`<font style="background-color:#F8F8F8;"> 就表示 </font>**<font style="background-color:#F8F8F8;">当前调用方法的对象自己</font>**
+ **<font style="background-color:#F8F8F8;">调用方法时</font>**<font style="background-color:#F8F8F8;">，程序员不需要传递 </font>`<font style="background-color:#F8F8F8;">self</font>`<font style="background-color:#F8F8F8;"> 参数</font>
+ **<font style="background-color:#F8F8F8;">在方法内部</font>**
    - 可以通过 `self.` **访问对象的属性**
    - 也可以通过 `self.` **调用其他的对象方法**
+ <font style="background-color:#F8F8F8;">改造代码如下：</font>

```plain
class Cat:
    def eat(self):
        print("%s 爱吃鱼" % self.name)
tom = Cat()
tom.name = "Tom"
tom.eat()
lazy_cat = Cat()
lazy_cat.name = "大懒猫"
lazy_cat.eat()
```

<font style="background-color:#F8F8F8;">￼</font>

+ <font style="background-color:#F8F8F8;">在 </font>**<font style="background-color:#F8F8F8;">类的外部</font>**<font style="background-color:#F8F8F8;">，通过 </font>`<font style="background-color:#F8F8F8;">变量名.</font>`<font style="background-color:#F8F8F8;"> 访问对象的 </font>**<font style="background-color:#F8F8F8;">属性和方法</font>**
+ <font style="background-color:#F8F8F8;">在 </font>**<font style="background-color:#F8F8F8;">类封装的方法中</font>**<font style="background-color:#F8F8F8;">，通过 </font>`<font style="background-color:#F8F8F8;">self.</font>`<font style="background-color:#F8F8F8;"> 访问对象的 </font>**<font style="background-color:#F8F8F8;">属性和方法</font>**

<h2 id="toc_12">04. 初始化方法</h2>
<h3 id="toc_13"><font style="background-color:#F8F8F8;">4.1 之前代码存在的问题 —— 在类的外部给对象增加属性</font></h3>
+ <font style="background-color:#F8F8F8;">将案例代码进行调整，</font>**<font style="background-color:#F8F8F8;">先调用方法 再设置属性</font>**<font style="background-color:#F8F8F8;">，观察一下执行效果</font>

```plain
tom = Cat()
tom.drink()
tom.eat()
tom.name = "Tom"
print(tom)
```

+ <font style="background-color:#F8F8F8;">程序执行报错如下：</font>

```plain
AttributeError: 'Cat' object has no attribute 'name'
属性错误：'Cat' 对象没有 'name' 属性
```

**<font style="background-color:#F8F8F8;">提示</font>**

+ <font style="background-color:#F8F8F8;">在日常开发中，不推荐在</font>**<font style="background-color:#F8F8F8;">类的外部</font>**<font style="background-color:#F8F8F8;">给对象增加属性</font>
    - 如果**在运行时，没有找到属性，程序会报错**
+ <font style="background-color:#F8F8F8;">对象应该包含有哪些属性，应该 </font>**<font style="background-color:#F8F8F8;">封装在类的内部</font>**

<h3 id="toc_14"><font style="background-color:#F8F8F8;">4.2 初始化方法</font></h3>
+ <font style="background-color:#F8F8F8;">当使用</font>`<font style="background-color:#F8F8F8;">类名()</font>`<font style="background-color:#F8F8F8;">创建对象时，会</font>**<font style="background-color:#F8F8F8;">自动</font>**<font style="background-color:#F8F8F8;">执行以下操作：</font>
    1. 为对象在内存中 **分配空间** —— 创建对象
    2. 为对象的属性 **设置初始值** —— 初始化方法(`init`)
+ <font style="background-color:#F8F8F8;">这个 </font>**<font style="background-color:#F8F8F8;">初始化方法</font>**<font style="background-color:#F8F8F8;"> 就是 </font>`<font style="background-color:#F8F8F8;">__init__</font>`<font style="background-color:#F8F8F8;"> 方法，</font>`<font style="background-color:#F8F8F8;">__init__</font>`<font style="background-color:#F8F8F8;"> 是对象的</font>**<font style="background-color:#F8F8F8;">内置方法</font>**

> `<font style="background-color:#F8F8F8;">__init__</font>`<font style="background-color:#F8F8F8;"> 方法是 </font>**<font style="background-color:#F8F8F8;">专门</font>**<font style="background-color:#F8F8F8;"> 用来定义一个类 </font>**<font style="background-color:#F8F8F8;">具有哪些属性的方法</font>**<font style="background-color:#F8F8F8;">！</font>
>

<font style="background-color:#F8F8F8;">在 </font>`<font style="background-color:#F8F8F8;">Cat</font>`<font style="background-color:#F8F8F8;"> 中增加 </font>`<font style="background-color:#F8F8F8;">__init__</font>`<font style="background-color:#F8F8F8;"> 方法，验证该方法在创建对象时会被自动调用</font>

```plain
class Cat:
    """这是一个猫类"""
    def __init__(self):
        print("初始化方法")
```

<h3 id="toc_15"><font style="background-color:#F8F8F8;">4.3 在初始化方法内部定义属性</font></h3>
+ <font style="background-color:#F8F8F8;">在 </font>`<font style="background-color:#F8F8F8;">__init__</font>`<font style="background-color:#F8F8F8;"> 方法内部使用 </font>`<font style="background-color:#F8F8F8;">self.属性名 = 属性的初始值</font>`<font style="background-color:#F8F8F8;"> 就可以 </font>**<font style="background-color:#F8F8F8;">定义属性</font>**
+ <font style="background-color:#F8F8F8;">定义属性之后，再使用 </font>`<font style="background-color:#F8F8F8;">Cat</font>`<font style="background-color:#F8F8F8;"> 类创建的对象，都会拥有该属性</font>

```plain
class Cat:
    def __init__(self):
        print("这是一个初始化方法")
        
        # 定义用 Cat 类创建的猫对象都有一个 name 的属性
        self.name = "Tom"
    def eat(self):
        print("%s 爱吃鱼" % self.name)
# 使用类名()创建对象的时候，会自动调用初始化方法 __init__
tom = Cat()
tom.eat()
```

<h3 id="toc_16"><font style="background-color:#F8F8F8;">4.4 改造初始化方法 —— 初始化的同时设置初始值</font></h3>
+ <font style="background-color:#F8F8F8;">在开发中，如果希望在</font>**<font style="background-color:#F8F8F8;">创建对象的同时，就设置对象的属性</font>**<font style="background-color:#F8F8F8;">，可以对</font>`<font style="background-color:#F8F8F8;">__init__</font>`<font style="background-color:#F8F8F8;">方法进行</font>**<font style="background-color:#F8F8F8;">改造</font>**
    1. 把希望设置的属性值，定义成 `__init__` 方法的参数
    2. 在方法内部使用 `self.属性 = 形参` 接收外部传递的参数
    3. 在创建对象时，使用 `类名(属性1, 属性2...)` 调用

```plain
class Cat:
    def __init__(self, name):
        print("初始化方法 %s" % name)
        self.name = name
    ...
    
tom = Cat("Tom")
...
lazy_cat = Cat("大懒猫")
...
```

<h3 id="toc_18"><font style="background-color:#F8F8F8;">5.1 </font>`<font style="background-color:#F8F8F8;">__del__</font>`<font style="background-color:#F8F8F8;"> 方法（知道）</font></h3>
+ <font style="background-color:#F8F8F8;">在</font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;">中</font>
    - 当使用 `类名()` 创建对象时，为对象 **分配完空间**后，**自动** 调用 `__init__` 方法
    - 当一个 **对象被从内存中销毁** 前，会 **自动** 调用 `__del__` 方法
+ **<font style="background-color:#F8F8F8;">应用场景</font>**
    - `__init__` 改造初始化方法，可以让创建对象更加灵活
    - `__del__` 如果希望在对象被销毁前，再做一些事情，可以考虑一下 `__del__` 方法
+ **<font style="background-color:#F8F8F8;">生命周期</font>**
    - 一个对象从调用 `类名()` 创建，生命周期开始
    - 一个对象的 `__del__` 方法一旦被调用，生命周期结束
    - 在对象的生命周期内，可以访问对象属性，或者让对象调用方法

```plain
class Cat:
    def __init__(self, new_name):
        self.name = new_name
        print("%s 来了" % self.name)
    def __del__(self):
        print("%s 去了" % self.name)
# tom 是一个全局变量
tom = Cat("Tom")
print(tom.name)
# del 关键字可以删除一个对象
del tom
print("-" * 50)
```

<h3 id="toc_19"><font style="background-color:#F8F8F8;">5.2 </font>`<font style="background-color:#F8F8F8;">__str__</font>`<font style="background-color:#F8F8F8;"> 方法</font></h3>
+ <font style="background-color:#F8F8F8;">在 </font>`<font style="background-color:#F8F8F8;">Python</font>`<font style="background-color:#F8F8F8;"> 中，使用 </font>`<font style="background-color:#F8F8F8;">print</font>`<font style="background-color:#F8F8F8;"> 输出 </font>**<font style="background-color:#F8F8F8;">对象变量</font>**<font style="background-color:#F8F8F8;">，默认情况下，会输出这个变量 </font>**<font style="background-color:#F8F8F8;">引用的对象</font>**<font style="background-color:#F8F8F8;"> 是 </font>**<font style="background-color:#F8F8F8;">由哪一个类创建的对象</font>**<font style="background-color:#F8F8F8;">，以及 </font>**<font style="background-color:#F8F8F8;">在内存中的地址</font>**<font style="background-color:#F8F8F8;">（</font>**<font style="background-color:#F8F8F8;">十六进制表示</font>**<font style="background-color:#F8F8F8;">）</font>
+ <font style="background-color:#F8F8F8;">如果在开发中，希望使用 </font>`<font style="background-color:#F8F8F8;">print</font>`<font style="background-color:#F8F8F8;"> 输出 </font>**<font style="background-color:#F8F8F8;">对象变量</font>**<font style="background-color:#F8F8F8;"> 时，能够打印 </font>**<font style="background-color:#F8F8F8;">自定义的内容</font>**<font style="background-color:#F8F8F8;">，就可以利用 </font>`<font style="background-color:#F8F8F8;">__str__</font>`<font style="background-color:#F8F8F8;"> 这个内置方法了</font>

> <font style="background-color:#F8F8F8;">注意：</font>`<font style="background-color:#F8F8F8;">__str__</font>`<font style="background-color:#F8F8F8;"> 方法必须返回一个字符串</font>
>

```plain
class Cat:
    def __init__(self, new_name):
        self.name = new_name
        print("%s 来了" % self.name)
    def __del__(self):
        print("%s 去了" % self.name)
    def __str__(self):
        return "我是小猫：%s" % self.name
tom = Cat("Tom")
print(tom)
```
