当我们创建进程数量不多的时候,但是我们的目标如果太多,手动的去创建进程的工作量就比较大,进程池



初始化进程池pool,可以指定一个最大进程数,当有新的请求提交到pool中时,如果池没有满,那么就会创建一个新的进程来执行该请求,但是如果进程数量达到最大值的时候,请求就会等待,直到我们进程池中有进程结束

**apply_async(func, args=(), kwds={}):使用非阻塞方式调用我的func(并行执行,堵塞方式必须等待上一个进程退出才能执行下一个进程)   **

**close()关闭pool**

**terminate()不管任务是否完成立即终止**

**join:主进程则色等待子进程的退出  必须在close或者****terminate之后使用**
