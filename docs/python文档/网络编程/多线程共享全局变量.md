1.在一个进程内所有的线程共享全局变量,很方便在多个线程间进行数据的共享

2.线程对全局变量的随意篡改会导致多个线程之间全局变量的混乱 线程不安全

```python
from threading import Thread
import time

g_num = 0

def fun1(num):
    global g_num
    for i in range(num):
        g_num += 1
        print("fun1,g_num is %d---" % g_num)

def fun2(num):
    global g_num
    for i in range(num):
        g_num += 1
        print("fun2,g_num is %d---" % g_num)

print("线程创建之前,g_num is %d---" % g_num)

t1 = Thread(target=fun1, args=(100,))
t1.start()

time.sleep(2)

t2 = Thread(target=fun2, args=(100,))
t2.start()

print("线程结束之后全局变量,g_num is %d---" % g_num)
```







线程创建之前,g_num is 0---

fun1,g_num is 100---

fun2,g_num is 200---

线程结束之后全局变量,g_num is 200---



#### 两个线程 t1、t2 都要对 g_num 值进行操作，这两个线程各自对 g_num 进行 100 次相加最终的结果应该是 200
#### 多线程操作的时候会出现下面这种情况
#### 1. g_num=0；t1 取得了这个值 g_num=0；系统会把 t1 调度为 sleep 状态，t2 变成运行状态，t2 g_num=0
#### 2. t2 对 g_num 进行加 1，现在 g_num=1
#### 3. t2 sleep，t1 开始运行，之前得到的 0 加 1 赋值给了 g_num=1
#### 4. 这样就导致 t1、t2 线程都对 g_num 加了 1，但结果仍然是 1


多个线程对同一个全局变量操作,会出现资源的竞争问题导致数据的不准确
