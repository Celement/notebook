<h4 id="iDc6d">2.进程语法结构</h4>
<font style="background-color:transparent;">Process(</font>

            group: Any = ...,

             target: Optional[Callable] = ...,

             name: Optional[<font style="color:#000080;">str</font>] = ...,

             args: Iterable[Any] = ...,

             kwargs: Mapping[Any, Any] = ...,

             *,

             )



**target:**如果我们传递了函数的引用,任务就在这个子进程执行这里的代码

**args:**给我们的target指定函数传递的参数,以元组的方式传递

**kwargs****:**给target指定的函数传递命名参数

**group:**指定进程组



**Process实例的常用方法**

**  start()**启动子进程

**is_alive()**判断进程子进程是否还活着

**join([timeout]):**是否等待子进程执行结束或者等待多少秒

**terminate():**不管任务是否完成立即终止子进程

**Prcoess**创建的实例的属性

**name:**当前进程的别名 从1开始递增 Process-N   

**pid:**进程号
