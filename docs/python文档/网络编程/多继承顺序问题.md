子类中通过父类名进行调用时,parent被执行了两次

通过super调用时parent被执行了一次



**1.super.__init__****相对于类名****.__init__ ****在我们单继承上用法没有差别的****  
****2.****但是在多继承上有区别****super****方法可以保证每个父类的方法只会被执行一次****,****类名的方法会导致方法被执行多次****  
****3.****多继承时使用****super****方法对父类传参数由于****python****中的****super****算法的原因必须把参数全部传递否则就会报错****  
****4.****单继承时使用****super****方法则不能全部传递只能传递父类方法所需的参数否则也会报错****  
****5.****多继承时相对于使用类名****.__init__****方法****,****要把每个父类全部写一遍****,****而使用****super****方法只需要一句话便执行了全部的父类方法****这个也是多继承需要全部传参的一个原因**
