<h4 id="Im39D">1.类属性,实例属性</h4>
定义和使用中有所区别,最本质的区别是内存中保存的位置不同

+ 实例属性属于对象
+ 类属性属于类
+ _类属性在内存中只保存一份__#__实例的属性 每个对象都要保存一份_
+ _应用场景通过类创建实例对象时__,__如果每个对象需要具有相同的名字的属性__,__那么我们就用类属性_
