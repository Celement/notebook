

<h4 id="bDt8o">1.进程</h4>


一个程序运行起来  代码加上的资源 称之为进程他是操作系统的基本单元,进程里面有多个线程

<h4 id="QS6nn">2.进程的状态</h4>


在工作中任务数大于cpu的核心数,一定有一些任务正在执行,另外的任务在等待cpu进行执行,那么就导致了有不同的状态

![](https://cdn.nlark.com/yuque/0/2020/png/1254889/1594022343764-ab8a2954-9542-4812-84ab-75f07438cabe.png)







就绪状态:运行的条件已经过去了正在等待在cpu中执行

执行状态:cpu正在执行功能

等状态:等条件满足的时候然后转成就绪的状态
