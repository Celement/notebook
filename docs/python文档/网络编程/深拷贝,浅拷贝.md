<h3 id="T6Aka">1. 浅拷贝</h3>
+ 浅拷贝是对于一个对象的顶层拷贝

通俗的理解是：拷贝了引用，并没有拷贝内容



<h3 id="LURcE">2. 深拷贝</h3>
+ 深拷贝是对于一个对象所有层次的拷贝(递归)
+ 确实是将a列表中的所有数据的引用copy  但是我们不是只拷贝了a指向的列表的引用

> **import **copy
>
> i=<font style="color:#0000ff;">18</font>ic=copy.deepcopy(i)
>
> <font style="color:#000080;">print</font>(ic)
>
> <font style="color:#000080;">print</font>(<font style="color:#000080;">id</font>(i))
>
> <font style="color:#000080;">print</font>(<font style="color:#000080;">id</font>(ic))
>
> t=(<font style="color:#0000ff;">1</font>,<font style="color:#0000ff;">2</font>,<font style="color:#0000ff;">3</font>)
>
> tc=copy.deepcopy(t)
>
> <font style="color:#000080;">print</font>(tc)
>
> <font style="color:#000080;">print</font>(<font style="color:#000080;">id</font>(t))
>
> <font style="color:#000080;">print</font>(<font style="color:#000080;">id</font>(tc))
>
