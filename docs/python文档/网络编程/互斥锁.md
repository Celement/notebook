当多个线程几乎同时修改某一个共享数据的时候需要进行同步控制

线程同步能够保证多个线程安全的访问竞争资源,互斥锁保证了每次只有一个线程进行写入操作,其他线程数据就是正确的了



threading  Lock类



创建锁

mutex=threading.Lock()

锁定

mutex.acquire()

mutex.release()

如果这个锁之前是没有上锁的那么不会堵塞

如果调用acquire对这个锁上锁之前被其他线程上了锁那么就会堵塞直到解锁为止



<h4 id="dM0WE">锁的好处</h4>
<h4 id="jmis4">确保了某段关键代码只能由一个线程从头到尾执行</h4>
<h4 id="3cHLC">坏处;</h4>
<h4 id="YNAxC">阻止了多线程的并发执行,包含锁的某段代码实际上就变成了单线程 效率就降低了</h4>
<h4 id="xNdr7">存在多个锁,不同的线程持有不同的锁,并试图打开对方的锁会造成死锁</h4>
