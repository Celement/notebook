+ 简单的来说就是我们的操作系统同时运行多个任务,一边上网,一边听歌,word做文档,这三个任务同时进行的,电脑还有很多任务在后台运行.
+ 现在我们的cpu是不是多核cpu 多个核心同时执行程序,单核也可以实现多任务 cpu顺序执行的
+ 任务1 0.01s 任务2 0.01 反复执行下去 从表面上看我们的任务是交替执行的 cpu速度特别快 感觉任务同时执行



  真正并行只能在多核cpu上去执行,实际中任务数是大于cpu的核心数量,所以说我们操作系统也会自动的把很多任务轮流调度到每个核心上执行



> 并发:指的就是任务数多于我们的cpu核心数,通过操作系统的各种调度算法,实现多个任务一起执行,实际过程中总有一些任务不在执行,因为切换任务的速度特别快看起来像是一起执行的
>
> 并行:指的就是任务数小于等于cpu核心数 任务真正的一起执行的
