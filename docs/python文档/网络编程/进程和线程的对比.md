<h4 id="w0J9W">1.功能</h4>
 进程能够完成我们的多任务,我们一台电脑能够运行多个qq

 线程能够完成多任务,一个qq可以有多个聊天窗口

**2.定义不同**

**进程是系统进行资源分配和调度的一个独立单元**

****

**线程是进程的一个实体,是cpu调度和分派的基本单位,他比进程更小能够独立运行的基本单位,线程自己基本上不拥有系统资源,只拥有一点在运行中必不可少的资源(程序计数器,寄存器,栈),但是他可以同属于一个进程的其他线程共享所拥有的全部资源**

****

**区别:**

+ **一个程序至少有一个进程,一个进程至少有一个线程**
+ **线程的划分尺度小于进程多线程程序的并发性高**
+ **进程在执行过程中拥有独立的内存单元,多个线程共享内存,提高程序的运行效率**
+ **线程不能够独立运行,必须依存在进程中**

**优缺点:**

线程执行开销小,但是不利于资源的管理和保护,进程恰恰相反
