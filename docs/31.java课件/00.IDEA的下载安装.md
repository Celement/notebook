# IDEA的下载安装

## IDEA下载、安装、卸载

- 下载 [https://www.jetbrains.com/idea/](http://www.eclipse.org)

- 安装 (一直下一步安装即可)

- 卸载（只需要在控制面板里跟普通软件一样就可以了）

- 注意： 开发软件的安装目录中，尽量不要出现空格与中文

## IDEA使用教程

- **IntelliJ IDEA创建java项目**

- 1.进入到IntelliJ IDEA启动界面，点击**Create New Project**

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190742.gif)

-   2.这样就进入到了创建项目页面，这里可以创建好多项目，这里我们以**java**项目为例开始一个新的旅程，选择你下载的jdk的版本即可。

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190742.gif)

-   3.继续

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190742.gif)

-   4.继续，除了标记位置，其他都是默认即可

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190742.gif)

-   5.这样你就进入了一个全新页面，这里就可以显示你创建的项目，是不是很快啊

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190742.gif)

-   6.选中src，右键新建一个包

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190742.gif)

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190656.gif)

-   7.接着在这个包下面新建一个java类

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190657.gif)

-   8.这里我们看到了熟悉的界面，编写一个简单的helloWorld.java

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190658.gif)

-   9.接下来我们运行我们写的HelloWorld.java

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190659.gif)

![](https://gitee.com/elementsong_admin/mdimage/raw/master/20201115190700.gif)

-   10.接着我们又看到了熟悉的界面，这样一个基本的java程序完成了
